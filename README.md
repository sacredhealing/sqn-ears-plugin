# SQN Ears

Siddha Quantum Nexus Music: a master plugin (AU / VST3) that listens to the mix and fixes it:
loudness, tone, mud, harshness, glue, width, mono bass, rumble and peaks. 11 sounds.

Every push to `main` builds a Mac installer (`SQN_Ears_Installer.pkg`) under Actions > Build Mac installer > Artifacts.
