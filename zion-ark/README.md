# Zion Ark

Siddha Quantum Nexus Music: a Kingston dub studio in one plugin (AU / VST3).
Big Knob 11-step high-pass, Twin Phase (dual photocell phaser), Space Tape Echo (3 heads), Thunder Spring (valve tank),
Dub Siren, Ark Tape 4 (mono, wow, hiss, drive) and reference match (Ark '77, Rebel '70, One '72, Now).

Every push to the `zion-ark` branch builds `Zion_Ark_Installer.pkg` (Releases > zion-ark-latest).
